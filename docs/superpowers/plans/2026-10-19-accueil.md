# Accueil Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un plugin Obsidian desktop qui affiche la page d'accueil du vault Mon Cerveau (Métier, Domaines, Au quotidien) d'après la maquette Figma « Accueil v2 ».

**Architecture:** Deux fonctions pures testées (lecture d'un `_État.md`, construction du modèle de la page à partir d'un arbre de dossiers abstrait) ; une `ItemView` Obsidian qui adapte le vault à cet arbre et dessine le modèle en DOM ; un onglet de réglages. Aucune écriture dans le vault.

**Tech Stack:** TypeScript, esbuild, API `obsidian`, Vitest pour les fonctions pures.

**Spec:** `docs/superpowers/specs/2026-10-19-accueil-design.md` — maquette Figma `NQs5DPaRjTEJhtu5cmJsX1`, node `6:71`.

## Global Constraints

- Aucune écriture dans le vault ; lecture via `app.vault.cachedRead` uniquement.
- Polices : Alata (titres, interface), Amethysta (texte) ; accent `#bd4747` ; variables CSS d'Obsidian là où elles existent.
- Le code vit dans `C:\Users\uriel\Desktop\DEVs\Plugin\` ; le build est copié dans `C:\Users\uriel\Desktop\MON CERVEAU (SYNC)\.obsidian\plugins\accueil\`.
- **Zones interdites à Claude** : `SÉNAQUE 2025/`, `SENAQUE Univers 2024/`, `4. L'ŒUVRE/`, `0. INBOX/SOUVENIRS/`. Aucun test, script ou outil ne les lit. Les tests utilisent des arbres fictifs.
- Copie française exacte : « Mon Cerveau. », « Où veux-tu aller ? », « Le Métier », « Les Domaines », « Au quotidien », « ce qui doit rapporter », « le foyer, l'atelier, l'œuvre », « les notes de tous les jours », commande « Ouvrir l'accueil ».

## Review Focus

- Un `_État.md` sans section `## Prochaine action`, ou une section vide → la ligne disparaît, pas de « undefined » (test dans Task 2).
- Un gras qui contient une parenthèse ou un deux-points dès le début (« **Le produit d'abord (08/10…) : on ne…** ») → « Le produit d'abord » (test dans Task 2).
- Un dossier `1. LE MÉTIER` absent ou vide → la section Métier n'apparaît pas, la page s'affiche quand même (test dans Task 3).
- Un nom de dossier numéroté sur deux chiffres ou sans espace (« 10. X », « 2.X ») → bien reconnu comme numéroté et trié numériquement (test dans Task 3).
- Un dossier du quotidien choisi puis supprimé ou renommé → section absente, pas d'erreur (test dans Task 3).

### Task 2: Lire la prochaine action d'un `_État.md`

**Files:**
- Create: `src/etat.ts`, `tests/etat.test.ts`

**Interfaces:**
- Produces: `extractNextAction(markdown: string): { text: string; more: number } | null`

- [ ] **Step 1: Write the failing tests**

```ts
// la section va de "## Prochaine action" au "## " suivant ; le frontmatter est ignoré
expect(extractNextAction("## Prochaine action\n\n**Définir le catalogue** — quels livres.\n\n## Tranché\n**Autre**"))
  .toEqual({ text: "Définir le catalogue", more: 0 });
// coupe avant la première parenthèse ou deux-points
expect(extractNextAction("## Prochaine action\n**Le produit d'abord (08/10, Uriel : « x ») : on ne relance pas**"))
  .toEqual({ text: "Le produit d'abord", more: 0 });
// +N = autres paragraphes qui commencent par du gras
expect(extractNextAction("## Prochaine action\n**Avant la bascule de la V2 à la racine, dans cet ordre (19/10)** : 1.\n**Battre** x\n\n**Distribuer.** y\ntexte"))
  .toEqual({ text: "Avant la bascule de la V2 à la racine, dans cet ordre", more: 2 });
// paragraphe en liste "- **X** :" compte aussi comme gras
expect(extractNextAction("## Prochaine action\n- **La refonte du Hub (lancée le 12/10)** : le Hub…\n- **J'y suis allé** x"))
  .toEqual({ text: "La refonte du Hub", more: 1 });
// sans gras : première ligne non vide
expect(extractNextAction("## Prochaine action\n\nAppeler le notaire.\n")).toEqual({ text: "Appeler le notaire.", more: 0 });
// sans section, ou section vide
expect(extractNextAction("# X\n## Où on en est\nbla")).toBeNull();
expect(extractNextAction("## Prochaine action\n\n## Tranché\n")).toBeNull();
```

### Task 3: Construire le modèle de la page

**Files:**
- Create: `src/model.ts`, `tests/model.test.ts`

**Interfaces:**
- Consumes: `extractNextAction` (Task 2).
- Produces:

```ts
export interface Node { name: string; path: string; kind: "folder" | "note" | "canvas"; children?: Node[]; etat?: string /* contenu du _État.md direct, s'il existe */ }
export interface Settings { accroches: Record<string, string>; quotidien: string | null; masques: string[] }
export interface Link { label: string; path: string; kind: "folder" | "note" | "canvas" }
export interface Metier { numero: number; romain: string; titre: string; accroche?: string; path: string; action?: { text: string; more: number }; sousProjets: { titre: string; text: string }[]; sousProjetsEnPlus: number }
export interface Domaine { numero: string /* "02" */; titre: string; accroche?: string; path: string; liens: Link[]; enPlus: number }
export interface Quotidien { dossiers: Link[]; notes: { emoji?: string; label: string; path: string }[] }
export interface HomeModel { metiers: Metier[]; domaines: Domaine[]; quotidien: Quotidien | null }
export function buildHome(root: Node, settings: Settings): HomeModel
export function splitEmoji(name: string): { emoji?: string; label: string }
```
